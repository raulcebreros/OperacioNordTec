***Llista de passos per pujar cambis a GitHub:***
* ***1- Si iniciem un nou prjecte primer hem d'escriure: git init***
* ***2- Després guardem els arxius que no estan guardats amb: git add <NOM DEL FITXER.md>***
* ***3- Amb la comanda: git commit -m "TEXT" prepareu l'arxiu per pujarlo al GITHUB***
* ***4- Si utilitzem git branch ens permet veure en quin punt estem actualment***
* ***5- Fem servir: git remote origin https://github.com/EL_TEU_USUARI/OperacioNordTec.git . Això ens permet indicar el nostre repositori***
* ***6- Per últim, escrivim: git push -u origin main per pujar l'arxiu a GitHub***
